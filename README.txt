WUB BLOOD — STUDENT BLOOD NETWORK
===================================
A polished, fully responsive, production-ready web platform for World University of Bangladesh (WUB) students to find blood, request blood, and register as active campus donors.

BRANDING & ARCHITECTURE
-----------------------
- Brand: WUB Blood
- Motto: Together We Learn, Together We Grow
- Target: World University of Bangladesh Student Community
- Theme: Deep Navy (#0E3A8A), Teal (#106881), Blood Red (#EF4444), Light Slate (#F8FAFC)
- Typography: Poppins, Inter, Dancing Script (Google Fonts)

PAGES
-----
index.html          Home Dashboard (Hero Banner + Live Find Blood donor grid)
find-blood.html     Full-page Donor Directory with multi-criteria filtering
request-blood.html  Blood Request Form with live active campus feed
become-donor.html   Donor Registration with Bangladeshi mobile validation
about.html          About WUB Blood, Compatibility Chart & Hotlines
login.html          Student & Admin Authentication (with 1-click demo autofill)
register.html       Student Account Registration
dashboard.html      Student Utility Dashboard
admin.html          Admin Console & Verification Queue
style.css           Complete Responsive Design System
script.js           Interactive Engine with LocalStorage persistence
assets/campus-bg.png Official WUB Permanent Campus Photograph
assets/WUB-Logo.png  Official World University of Bangladesh Emblem / Crest Logo

HOW TO RUN
----------
1. Open index.html in any modern browser (Chrome, Edge, Firefox, Safari).
2. Or use VS Code "Live Server" extension.
3. No build tools or server installation needed. All features run client-side with persistent LocalStorage state.

FEATURES
--------
- Real-time donor filtering by Blood Group, Location, Department, and search query.
- Instant Contact Modal with direct Call and WhatsApp message links.
- Verified form validation (11-digit BD mobile numbers, student IDs).
- Complete session management (Login, Register, Dashboard, Logout).
- Full responsiveness across Mobile (320px+), Tablet, and Desktop (1920px+).
